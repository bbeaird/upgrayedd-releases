Upgrayedd Privacy Policy

Effective 2026-10-23 · Developer: Brantley Beaird

What stays on this Mac

Upgrayedd records performance data (CPU, memory, swap, disk space, thermal and power state, process names with their CPU and memory use, the frontmost app's bundle ID, whether you are active or idle, and your Mac's model and specs) in a local database in ~/Library/Application Support/Upgrayedd. Reports and exports are saved beside it. None of this is sent anywhere. Encrypted backups go only to a folder you choose; if that folder syncs to a cloud service, that service uploads the encrypted files.

Usage analytics

On by default. Release builds send these events to Segment, which forwards them to Google Analytics:

  • app_opened: once per launch, and when you turn sharing back on
  • screen_view: when Overview or Detailed Stats appears
  • explanation_opened: when you tap “Why?”

Each event carries app, platform, app_version, environment, session_id (the time the app started), engagement_time_msec (always 1), screen_name (overview or details, screen views only), a timestamp, a random message ID and a random identifier. The identifier is created at each launch, kept only in memory, and replaced when you turn sharing off or on. No performance data, app names or files are included.

For analytics your Mac connects only to Segment, so Segment sees your IP address; each event's own IP field is set to 0.0.0.0. Google Analytics receives the events from Segment. Nothing is sent before the first-run step has been shown, and events are never stored on disk or retried.

To turn it off, clear “Shares anonymous usage stats” in the first-run step, or “Share anonymous usage stats” in Upgrayedd → Settings…. This stops future sends; it does not delete events already sent.

Privacy policies: Segment (Twilio) · Google

Other network connections

  • Update checks (release builds): about once a day if you chose Check Daily, and whenever you choose Check for Updates…, Upgrayedd requests its signed update feed from GitHub. GitHub sees your IP address and the app version. No performance data or system profile is sent. An update downloads from GitHub only after you approve it.
  • Apple links (“Configure at Apple”, “This Mac's specs at Apple”) open apple.com in your browser only when you click them.
  • Upgrayedd uses no AI, cloud or lookup services.
